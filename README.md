# 모션베드 온라인 견적 페이지

`가격표` 탭의 판매가를 기준으로 마베드·슈브의 프레임, 헤드·협탁, 테이블, 무드등, 매트리스, 배송비를 계산합니다. 세트 상품과 세트 할인은 사용하지 않습니다.

고객 화면의 공식 페이지명은 **버킷츠 구매 가이드**이며, 상단에 버킷츠 로고를 표시합니다.

## Apps Script 연결

1. 가격표 Google Sheets에서 **확장 프로그램 → Apps Script**를 엽니다.
2. 기본 코드를 지우고 `Code.gs` 내용을 붙여 넣어 저장합니다.
3. `testQuoteCatalog` 함수를 한 번 실행해 가격 항목 수가 표시되는지 확인합니다.
4. **배포 → 새 배포 → 웹 앱**을 선택합니다.
5. 실행 사용자는 **나**, 액세스 사용자는 **모든 사용자**로 설정합니다.
6. 끝이 `/exec`인 배포 URL을 복사합니다.
7. `index.html`의 아래 설정에 URL을 넣습니다.

```js
appsScriptUrl: 'https://script.google.com/macros/s/AKfycbwdgY1rRdsMUP62MNsp-vlAwKycuvTuxU3wNEC41LQGCy65fhaSyK052nue561VM3YA/exec',
```

`Code.gs`는 가격표를 읽기만 하며 셀을 수정하거나 고객 정보를 저장하지 않습니다.

## GitHub Pages 공개

1. 이 폴더의 `index.html`과 `assets` 폴더를 GitHub 저장소에 업로드합니다.
2. 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택합니다.
3. Branch는 `main`, 폴더는 `/(root)`로 설정합니다.
4. 생성된 `https://아이디.github.io/저장소명/` 주소를 고객에게 전달합니다.

## 현재 UI 구성

- 견적보다 침대 이해를 먼저 돕는 화이트톤 소개형 화면
- MY BED 01 가이드에서 마베드·슈브를 바꿔 보며 프레임부터 무드등까지 사진과 설명을 세로로 안내
- 가이드 맨 아래에서 실제 견적에 담을 마베드·슈브 제품을 선택
- MY BED 01 가이드·제품 → 02 프레임 규격·색상 → 03 매트리스 → 04 헤드·협탁 → 05 테이블 → 06 무드등 → 07 배송지역 순서
- 제품을 선택한 뒤 `다음 · 프레임 선택` 버튼으로 다음 단계에 이동
- 모바일 매트리스·헤드·테이블·무드등 카드는 한 장씩 옆으로 넘겨 보고, 마지막 다음에는 첫 카드로 순환
- 모바일에서는 제목·설명·옵션명·가격·버튼·최종 안내 글자를 더 크게 표시해 고령 고객의 가독성을 강화
- 가이드 하단 제품 버튼과 헤드·테이블·무드등·매트리스 카드는 박스 전체 또는 `선택하기` 버튼을 눌러 선택
- 슈브 선택 시 보에르 Fog를 기본 선택하며, 커스텀 패브릭 목록을 펼쳐도 첫 번째에 선택된 상태로 다시 표시
- 커스텀 패브릭 안내를 펼치면 제공받은 전체 소재·기능·색상 안내 이미지를 그대로 표시하고, 목록 아래의 버튼으로 바로 접기
- 마베드 화이트·그레이·내추럴 선택 시 해당 색상의 프레임 렌더링을 바로 표시
- 새로 열거나 새로고침하면 어떤 항목도 미리 선택하지 않음
- `헤드 없음`, `테이블 없음` 같은 불필요한 카드는 표시하지 않으며 선택하지 않으면 견적에서 제외
- 수동·자동 테이블은 고객이 직접 누른 경우에만 견적에 포함
- 옵션 카드마다 해당 부분의 이미지와 충분한 설명을 항상 펼쳐 표시
- 헤드와 협탁을 하나의 구성으로 묶어 불가능한 조합 방지
- 협탁은 별도 안내 사진으로 보여주고, 무드등 한쪽은 설치 시 기사님과 위치를 협의하며 양쪽은 프레임 하부 좌우에 모두 설치
- 사진에서 가려진 자동레일은 예상 설치 위치와 함께 별도 안내
- SS+SS 규격의 수동·자동 테이블 선택 차단 및 설치 불가 이유 표시
- 마베드·슈브의 실제 상세페이지 이미지를 사용한 헤드·협탁·자동레일·무드등 설명
- 하루끝 스프링과 라텍스폼 매트리스 제품 이미지를 같은 비율로 표시하고, 하루끝은 모션베드용으로 새롭게 개발한 전용 스프링 매트리스임을 안내
- 커플 규격 선택 시 싱글·트윈 확장 구조 안내 이미지 표시
- 선택 옵션에 맞춘 예상 가로·세로·높이와 매트리스 크기 자동 계산
- 화면 하단에 프레임 → 매트리스 → 헤드·협탁 → 테이블 → 무드등 → 배송지역 순서로 선택한 옵션을 각각의 텍스트 박스에 표시
- 하단 고정 영역의 어느 곳을 눌러도 선택한 사양과 최종 견적으로 바로 이동
- 배송 단계에는 충청·강화도·영종도·동두천·포천·연천을 생략하지 않고 모두 표시
- 화면 오른쪽의 `옵션 바로가기`를 누르면 세로형 목차가 열리며, 모바일에서는 평소 접힌 상태로 화면을 가리지 않음
- 프레임을 완성하지 않아도 매트리스 이후의 사진·설명과 `최저 가격부터` 안내를 모두 볼 수 있고, 각 카드의 선택 버튼은 `프레임 사양 먼저 선택`으로 표시되어 프레임 단계로 이동
- 제품을 아직 고르지 않아도 프레임 단계에서 공통 사이즈와 마베드·슈브 기본 컬러를 확인하고 선택할 수 있음
- 견적 복사·카카오톡 상담·전화 상담을 첫 줄에 배치하고, 이미지 저장·처음부터 다시를 둘째 줄에 크게 표시
- 최종 견적에서 제품·규격·색상·매트리스·헤드·테이블·무드등·배송지역을 드롭다운으로 바로 변경하거나 제외
- 이미지 저장 시 고객 정보와 견적 내용을 PNG 파일로 내려받고, 수정·상담 버튼은 이미지에서 제외
- 전화 상담 버튼은 `0507-1301-7653`으로 바로 연결
- 최종 견적 아래에 신한은행 입금 계좌와 계좌 정보 복사 버튼 표시
- 고객명·연락처·주소 검색·상세주소·배송 요청사항을 입력하면 복사 견적에 함께 포함
- 이브자리 매장에서 안내받은 고객을 위한 매장 연락 안내 문구 표시

설계 이미지는 옵션이 더해질 때 침대 모습이 어떻게 달라지는지 설명하는 안내용입니다. 실제 색상과 마감은 선택한 제품에 따라 달라집니다.
